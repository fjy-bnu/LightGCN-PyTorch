二、为什么不建议本地直接跑正式实验

LightGCN 在 Gowalla 数据集上默认训练轮数较多，例如 1000 轮。
之前本地 CPU 运行时，训练到少数轮数就已经耗时较长。

因此，本地电脑适合做：

1. 代码开发
2. 小样本流程验证
3. 数据统计
4. 指标脚本编写
5. 结果文件整理

但不适合直接进行完整正式训练。

五、正式实验推荐流程

第一步：
在 GPU 环境中 clone 当前 GitHub 仓库，并切换到 exposure-analysis 分支。

第二步：
重新配置 conda 环境或 Python 环境。

第三步：
运行 LightGCN 正式训练，例如先尝试 100 轮或 300 轮，不建议一开始直接 1000 轮。

第四步：
训练完成后，使用保存好的 checkpoint 导出完整测试用户 Top-20 推荐结果：

python export_gowalla_topk_full.py --dataset=gowalla --tensorboard=0

第五步：
运行完整曝光分析脚本：

python analyze_gowalla_exposure_full.py

第六步：
保存正式结果，包括：

results/gowalla_top20_recommendations_full.csv
results/gowalla_exposure_full_summary.txt
